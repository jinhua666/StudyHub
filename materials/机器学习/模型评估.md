# 分类模型评估：准确率、精确率与召回率

## 混淆矩阵

对于二分类，TP 是正确预测为正的数量，FP 是错误预测为正的数量，FN 是漏掉的正例数量，TN 是正确预测为负的数量。

| 指标 | 公式 | 关注点 |
| --- | --- | --- |
| 准确率 | $(TP+TN)/(TP+TN+FP+FN)$ | 整体预测正确比例 |
| 精确率 | $TP/(TP+FP)$ | 预测为正的样本有多少是真的 |
| 召回率 | $TP/(TP+FN)$ | 实际正例有多少被找出 |
| F1 | $2PR/(P+R)$ | 精确率与召回率的调和平均 |

当分母为零时，具体实现需要约定结果或报告该指标无法计算。

## 选择指标

类别极不平衡时，即使模型总预测多数类，准确率也可能很高。漏检代价高时应重点关注召回率；误报代价高时应重点关注精确率。分类阈值变化会影响两者，应在验证集上选择阈值，并在独立测试集上报告最终结果。根据任务需要还可查看 PR 曲线、ROC-AUC、混淆矩阵和概率校准情况。

## 练习

某模型有 TP=40、FP=10、FN=20、TN=930。计算准确率、精确率、召回率和 F1，并解释为什么不能只看准确率。
