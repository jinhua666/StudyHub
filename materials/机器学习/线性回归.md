# 线性回归：从目标函数到梯度下降

## 问题与模型

回归预测连续数值。例如用房屋面积和房龄预测价格。线性回归使用特征的加权和：

$$\hat y = w^\top x + b$$

其中 $x$ 是特征向量，$w$ 是权重，$b$ 是偏置。模型对参数是线性的，并不要求原始特征只能是一阶项；例如也可以加入面积的平方作为新特征。

## 训练目标

常见目标是最小化训练集均方误差（MSE）：

$$J(w,b)=\frac{1}{n}\sum_{i=1}^{n}(w^\top x_i+b-y_i)^2$$

梯度下降按负梯度方向迭代：$w \leftarrow w-\eta\nabla_wJ$，$b \leftarrow b-\eta\frac{\partial J}{\partial b}$。学习率 $\eta$ 太大可能震荡或发散，太小则收敛缓慢。特征尺度差异很大时，标准化通常有助于优化。

```python
import numpy as np
x = np.array([1., 2., 3.])
y = np.array([2., 4., 6.])
w, b, lr = 0., 0., 0.05
for _ in range(1000):
    error = w * x + b - y
    w -= lr * 2 * np.mean(error * x)
    b -= lr * 2 * np.mean(error)
print(round(w, 2), round(b, 2))
```

## 实践检查

先划分训练集和测试集，再只用训练集拟合标准化参数，避免数据泄漏。比较测试集的 MAE、RMSE 和基线模型；残差呈系统性曲线时，线性假设可能不足。正则化可以约束权重：岭回归使用 L2 惩罚，Lasso 使用 L1 惩罚。

## 练习

1. 为示例加入噪声并绘制损失随迭代次数的变化。
2. 尝试不同学习率，观察何时收敛、震荡或发散。
