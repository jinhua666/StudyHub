# Transformer：缩放点积注意力

## 核心思想

注意力根据查询（Query）与各个键（Key）的相关性，对对应的值（Value）加权求和。自注意力中，Q、K、V 通常由同一输入序列经过不同的线性映射得到；交叉注意力中，查询与键值可以来自不同序列。

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V$$

如果序列长度为 $n$，每个头的 Q、K 维度为 $d_k$，则 $QK^\top$ 产生 $n\times n$ 的相似度矩阵。除以 $\sqrt{d_k}$ 有助于避免维度较大时点积过大，让 softmax 过度饱和。掩码 $M$ 可屏蔽填充位置或未来位置。

## 多头与位置信息

多头注意力并行使用多个投影，让模型在不同表示子空间计算注意力，然后拼接各头并再次投影。注意力本身不直接编码顺序，因此模型还需要位置编码或其他位置机制。经典自注意力的注意力矩阵随序列长度平方增长，长序列会带来较高的计算和内存成本。

```python
import numpy as np
Q = np.array([[1., 0.], [0., 1.]])
K = Q.copy()
V = np.array([[1., 2.], [3., 4.]])
scores = Q @ K.T / np.sqrt(K.shape[-1])
weights = np.exp(scores - scores.max(axis=-1, keepdims=True))
weights /= weights.sum(axis=-1, keepdims=True)
print(weights @ V)
```
