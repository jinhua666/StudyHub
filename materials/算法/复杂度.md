# 时间与空间复杂度入门

## 大 O 表示什么

大 O 描述输入规模增长时资源消耗的渐近上界。它忽略常数系数和低阶项，用于比较增长趋势；实际耗时还受常数、数据分布、实现和硬件影响。

| 操作模式 | 常见时间复杂度 |
| --- | --- |
| 访问数组中已知位置 | $O(1)$ |
| 每次将搜索范围减半 | $O(\log n)$ |
| 遍历一次数组 | $O(n)$ |
| 比较排序的典型复杂度 | $O(n\log n)$ |
| 两层各遍历 n 次的循环 | $O(n^2)$ |

## 如何分析

先明确输入规模，再数关键操作执行次数。顺序代码的复杂度相加后保留增长更快的项；嵌套循环要看每层实际迭代范围，不能机械地相乘。空间复杂度通常统计随输入增长的额外空间，递归调用栈也需要计算。

```python
def contains_duplicate(items):
    seen = set()
    for item in items:
        if item in seen:
            return True
        seen.add(item)
    return False
```

在哈希集合操作平均为 $O(1)$ 的假设下，时间和额外空间均为平均 $O(n)$。实际最坏情况取决于哈希实现和输入。
