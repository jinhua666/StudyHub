# 动态规划：状态、转移与边界

动态规划将具有重叠子问题的计算组织起来，避免重复求解。关键不是套模板，而是明确状态代表什么、如何由更小的状态转移，以及初始条件是否覆盖了边界。

## 例子：爬楼梯

假设每次爬 1 或 2 阶，设 `dp[i]` 为恰好爬到第 `i` 阶的方法数。最后一步只能来自 `i-1` 或 `i-2`，因此：

$$dp[i] = dp[i-1] + dp[i-2]$$

令 `dp[0] = 1` 表示不走任何一步也是一种构造方式，`dp[1] = 1`。当只需要前两个状态时，可以将额外空间压缩至 $O(1)$。

```python
def climb_stairs(n):
    if n < 0:
        raise ValueError('n must be non-negative')
    previous, current = 1, 1  # dp[0], dp[1]
    if n == 0:
        return previous
    for _ in range(2, n + 1):
        previous, current = current, previous + current
    return current
```

时间复杂度 $O(n)$。这个空间优化适合只需要最终数量的场景；如果需要恢复具体路径，可能还需要保存额外信息。

## 练习

改为每次可爬 1、2、3 阶。定义状态、写出转移和初始条件，再用小输入手动验证结果。
