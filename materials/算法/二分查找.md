# 二分查找：边界与循环不变量

## 适用条件

二分查找需要可被二分的单调条件。例如已排序数组中，谓词 `a[i] >= target` 从假变为真。目标可以是找某个值，也可以是找满足条件的第一个位置。

## 左闭右开实现

```python
def lower_bound(a, target):
    left, right = 0, len(a)
    while left < right:
        mid = left + (right - left) // 2
        if a[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left

assert lower_bound([1, 2, 2, 4], 2) == 1
assert lower_bound([1, 2, 2, 4], 3) == 3
assert lower_bound([], 3) == 0
```

循环始终保持答案位于候选边界 `[left, right]` 中；当 `a[mid] < target` 时，`mid` 及其左侧都不可能是答案，因此 `left = mid + 1`。否则 `mid` 仍可能是答案，令 `right = mid`。返回 `len(a)` 表示所有元素都小于目标。时间复杂度 $O(\log n)$，额外空间 $O(1)$。

## 练习

将条件改成查找第一个大于目标的位置。测试空数组、所有元素相同、目标小于最小值和大于最大值的情况。
