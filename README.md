# StudyHub

StudyHub 是一款帮助你学习和整理知识的 Windows 软件。把学习资料按自己的习惯组织起来，随时查找、阅读和复习，让知识积累更有条理。

支持多级分类、Markdown 文档、数学公式、配图、搜索和数据备份。

## 安装与迁移

从 [Releases](../../releases/latest) 下载安装程序，选择安装位置；学习文档技能会自动安装。软件需要 Microsoft Edge WebView2 Runtime。

迁移数据时，在旧电脑首页选择“备份数据”，在新电脑选择“恢复备份”并导入 ZIP。恢复会覆盖目标知识库，请先备份。安装包不包含个人文档。

源码构建和使用说明见 [使用与迁移](docs/使用与迁移.md)。
