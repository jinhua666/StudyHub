# StudyHub

本地优先的个人计算机技术知识库。前端使用 Vue 3、TypeScript 和 Vite，后端使用 FastAPI、SQLAlchemy 和 SQLite。知识正文保留为 Markdown；分类以父子关系存储，层级不设固定上限。

## 使用 Windows 桌面版

推荐双击 `installer-output\StudyHub-Setup.exe`，在安装向导中选择安装目录。安装程序会创建开始菜单快捷方式，并自动为当前 Windows 用户安装 `studyhub-learning-doc` 技能。安装前若同名技能已有不同内容，安装程序会在该技能目录下保留一份 `SKILL.md.before-studyhub-install-*` 备份。重新打开 Codex 或开启新对话后即可使用技能。

安装程序只包含软件和技能，不包含你的私人知识数据。卸载软件不会自动删除知识库或已安装的技能。程序需要 Microsoft Edge WebView2 Runtime，缺少时请从微软官网安装。

未使用安装包时，也可采用以下方式：

双击 `release\StudyHub\StudyHub.exe`（或 `scripts\start.bat`）打开独立桌面窗口，不需要手动运行服务或打开浏览器。复制或移动程序时请保留整个 `release\StudyHub` 文件夹，不能只复制 EXE。程序使用 Microsoft Edge WebView2 Runtime；如果系统缺少该组件，需先从微软官方渠道安装。

程序、知识库和附件分开保存。桌面版使用原来的 `%LOCALAPPDATA%\StudyHub\`，已有资料无需重新导入；删除或替换程序文件夹不会自动删除这个数据目录。

## 从源码构建（Windows）

需要 Python 3.11 或更新版本，以及带 npm 的 Node.js 20 或更新版本。在项目目录的 PowerShell 中执行：

```powershell
py -3 -m venv backend\.venv
backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
backend\.venv\Scripts\python.exe -m pip install -r backend\requirements-desktop.txt
cd frontend
npm install
npm run build
cd ..
```

在项目根目录运行 `scripts\build-desktop.bat` 生成桌面版。开发时可运行 `scripts\dev.bat` 启动开发服务器。桌面版在内部使用仅监听本机的随机端口连接界面与 API，关闭窗口时服务随程序退出。

首次启动会初始化数据库和默认分类。数据库及附件位于 `%LOCALAPPDATA%\StudyHub\`，与项目代码分离；`STUDYHUB_DATA_DIR` 可覆盖该路径。`backups` 目录保存恢复前自动创建的安全备份。

## 迁移到新电脑或移动软件

**同一台电脑移动程序**：关闭 StudyHub，将整个项目文件夹移动到新位置，之后双击新位置的 `release\StudyHub\StudyHub.exe`。知识数据保存在本机用户数据目录，与程序位置无关。已安装的学习文档技能通过正在运行的 StudyHub 查找本机接口，不依赖旧项目路径。

**换电脑**：

1. 在旧电脑打开正在使用的 StudyHub，在首页点击“备份数据”，将 ZIP 保存到安全位置。这是包括数据库与附件的完整备份；“导出知识库”用途不同，不能替代恢复备份。先确认最新改动已保存。
2. 将 `installer-output\StudyHub-Setup.exe` 和刚导出的 ZIP 复制到新电脑。运行安装程序，自选安装目录；安装完成后启动 StudyHub。若提示缺少 Microsoft Edge WebView2 Runtime，请从微软官网安装。
3. 在新电脑的 StudyHub 首页选择“恢复备份”，选择 ZIP 并确认。恢复会覆盖新电脑当前知识库，并先为其创建一份安全备份；确认无误前保留旧电脑的数据和原始 ZIP。
4. 检查文档数量、分类、公式和附件。外部图片链接需要联网，不会包含在备份中。
5. 安装程序已自动安装学习文档技能。安装或打开 Codex 后开启新对话即可使用 `$studyhub-learning-doc`。若新电脑之后设置了不同的 `CODEX_HOME`，需将技能复制到该目录的 `skills\studyhub-learning-doc` 下，或使用源码包中的 `scripts\install-skill.bat` 重新安装。

项目根目录的 `StudyHub-migration-backup.zip` 是本次生成的快照，只包含生成时的数据；之后继续学习和编辑时，迁移前应重新通过软件导出最新备份。备份包含私人学习资料，请妥善保管。

## 操作

- 左侧选择分类，使用展开按钮浏览子树；将分类拖至目标行中间可移动到目标分类内，拖至目标行上缘或下缘可调整顺序。分类页面的上下箭头也可排序。系统一级板块不可删除或移入其他分类。删除分类时可选择迁移直属文档与子分类，或确认删除整个子树。
- 文档可在编辑器中更换分类、状态、难度和标签。阅读页提供目录、收藏、附件、复制和导出。Ctrl+K 聚焦搜索，输入后按 Enter 搜索。
- 顶部导入支持选择多个 Markdown 文件或递归选择文件夹，预览后选择是否创建分类以及遇到文档 ID 时的处理方式。格式见 [导入规范](docs/AGENT_IMPORT_FORMAT.md)。
- 首页可导出知识库 ZIP、下载完整备份，或恢复先前的备份。恢复会覆盖当前数据并先自动备份。建议在恢复前手动下载一份备份。
- 分类页可导出包含子树的 ZIP，阅读页可导出单篇 Markdown。附件随分类或全库 ZIP 一起导出；备份包含数据库及所有附件。

## 目录

`backend/app` 包含 API、模型、数据库和服务；`backend/alembic` 包含迁移配置；`frontend/src` 包含界面；`docs` 包含 API 和导入规范；`scripts` 包含 Windows 启动脚本。首次启动使用 SQLAlchemy 创建初始表，后续 schema 变更应通过 Alembic 管理；已有初始数据库可在 `backend` 下执行 `alembic stamp 0001_initial` 后应用后续迁移。

## 当前限制

搜索使用 SQLite LIKE，支持中文子串但未启用 FTS5；大库性能未优化。附件尚不能在编辑器中自动插入到正文。导入按文档 ID 检测重复，没有 ID 时始终新建。

`materials` 目录包含九篇入门资料，涵盖机器学习、前后端和算法。可运行 `backend\.venv\Scripts\python.exe scripts\import_starter.py` 将缺少的资料导入当前数据目录；同分类同名文档会被跳过，不覆盖已有内容。
